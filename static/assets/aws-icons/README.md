# AWS Architecture Icons used on this site

Source: the official AWS Architecture Icons asset package, release 31 July 2026
(Q3 2026), file `Icon-package_07312026.zip`, linked as "Icon package" from
https://aws.amazon.com/architecture/icons/

Downloaded: 4 November 2026.

AWS allows customers and partners to use these icons in architecture diagrams and
in materials such as whitepapers, presentations and data sheets. On this site they
appear only to depict the AWS service they belong to (the reference architecture,
framework rows and "built with" panels), each next to its service name. They are
byte-identical copies of the package files: not recoloured, cropped or redrawn,
and never used as the Monovus logo.

services (Runtime, Gateway, Policy, Identity, Memory, Observability, Evaluations) or
